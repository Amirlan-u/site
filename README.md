# AnimeShelf

Локальный каталог аниме для Raspberry Pi 3B. Интерфейс полностью тёмный, без отображения обложек. Тайтлы, сезоны, серии и озвучки определяются по папкам и видеофайлам. База данных и сборка не требуются.

## Запуск

Установите Python 3 и из корня проекта запустите:

```bash
python3 server.py --host 0.0.0.0 --port 8080
```

На Raspberry Pi можно запустить `sh start-pi.sh`. В Windows дважды щёлкните `start-windows.bat` или выполните `py -3 server.py` в терминале. Сервер напечатает два вида адресов: `127.0.0.1` для самого устройства и адрес локальной сети для другого устройства. **В браузере другого устройства используйте адрес локальной сети, не `0.0.0.0` и не `127.0.0.1`.** Оба устройства должны быть подключены к одной сети. Окно сервера оставьте открытым.

Запускать `python3 -m http.server` теперь нельзя: он не создаёт каталог из папок и не обрабатывает перемотку больших видео.

### Если адрес не открывается

1. На Raspberry Pi откройте напечатанный адрес `http://127.0.0.1:8080/`. Если он не открывается, посмотрите ошибку в терминале сервера.
2. На другом устройстве откройте напечатанный адрес вида `http://192.168.1.50:8080/`. Важно указать `http://` и порт `:8080`.
3. Если локально сайт работает, а с другого устройства нет, проверьте, что устройства в одной Wi-Fi/LAN сети и гостевая сеть не изолирует клиентов. На Pi узнайте IP командой `hostname -I` и сравните его с адресом сервера.
4. Если порт занят, запустите `python3 server.py --port 8081` и откройте адрес с `:8081`.
5. Если Pi подключён к сети, но соединение блокируется, проверьте локальный брандмауэр: для `ufw` — `sudo ufw status`; если он активен, разрешите `sudo ufw allow 8080/tcp`. На Windows разрешите Python входящие подключения в частной сети.

## Структура папок

```text
dist/
├── index.html
├── app.js
├── styles.css
├── Пример аниме/
│   └── season 1/
│       └── 01 - Оригинал.mp4
└── Моё аниме/
    ├── cover.jpg                 # Можно хранить, сайт не показывает обложки
    ├── season 1/
    │   ├── 01 - AniLibria.mp4
    │   ├── 01 - Другая озвучка.mp4
    │   └── 02 - AniLibria.mp4
    └── season 2/
        └── 01 - AniLibria.mp4
```

Название тайтла берётся из имени папки первого уровня. Поддерживаются папки `season`, `season 1`, `season 2`, `сезон 1`, `сезон 2` и просто `1`, `2`. Если папка `season` без номера, это сезон 1. Сезон показывается, только если в нём есть видео. Серии определяются по числу в начале файла: `01.mp4`, `01 - Озвучка.mp4` или `episode 01 - Озвучка.mp4`. Часть после номера считается названием озвучки. Можно также сделать папки озвучек внутри сезона, например `season 1/AniLibria/01.mp4` и `season 1/Другая озвучка/01.mp4`.

Поддерживаемые расширения: `.mp4`, `.m4v`, `.webm`, `.ogg`, `.ogv`. Фактическое воспроизведение зависит от кодеков браузера; надёжный вариант — MP4 с H.264 и AAC.

Каталог обновляется при каждой загрузке страницы. После добавления файлов достаточно обновить сайт в браузере. Пример можно удалить из `dist`, когда добавите свои тайтлы.

Прогресс хранится в `localStorage` каждого браузера: название тайтла, сезон, серия, озвучка и точное время просмотра. Между устройствами он не синхронизируется. Для сохранения истории не переименовывайте папку тайтла.

Плеер показывает название тайтла, сезон, серию и озвучку поверх видео при паузе. Выбор сезона, серии и озвучки, полоса перемотки, громкость и полный экран находятся на самом видео. Пробел или K переключают воспроизведение, стрелки влево и вправо перематывают на 10 секунд, когда фокус на плеере.
